    COF · AN OPEN FORMAT

    An open file format that bundles everything that defines an AI character — personality, looks, voice, 3D, motion, agent skills, memories and a psyche — with its rights and consent built in. The same file opens in a chat app, an image generator, ComfyUI, a game engine or an agent.

    Now: 1.2.2, 15 November 2026 — the builder keeps everything it does not model, agent hosts in cof-cli (one memory, two homes), undated memories in the explorer (notes). Before: 1.2.1, 8 November — Character.AI import; 1.2, 8 November — a psyche; 1.1, 30 October — memories; 1.0, 17 October. Every 1.x file stays valid and readable by every 1.x tool.

    Who she is

    A character is more than a prompt. Her psyche — eleven kinds of nodes, each tied to the memory, person or place it comes from — explored, played through time, written in the builder, then turned into the SOUL.md an agent reads.

    What's in a .cof

    A ZIP archive with a manifest: the character's identity, its elements in eight categories — personality (a Character Card V3 inside, a psyche, free text), appearance, identity weights, 3D, voice, postures, motion, memories — a library of agent files, and its rights. Almost everything is optional; what goes in is checked.

    Every version, one file

    A preset is a ready-to-use combination: one personality, one look, one voice, one age. Switch the language or the age, and the rest follows.

    A past, not just a description

    Moments and periods of a life, each with when, where, with whom, how it felt then and now, how clearly it comes back, and what the character would rather not tell. What it lives with a user is written back into the same file — and leaves with it. Read more.

    An inner life, and what it holds on to

    Values, beliefs, wants, fears, wounds, tastes and habits as a graph of short nodes, each with a strength, a time span and the memory it comes from. People, places and objects are named once, shared by memories and psyche. Read more.

    Its rights travel with it

    Permissions, consent when a real person is depicted, and provenance are part of the file. Every preset declares an age; nudity or intimate content with a minor makes a file invalid, not merely tagged.

    Several characters, one file

    A cast travels together, and each character keeps its own looks, voice, presets and rights.

    Make it once. Use it everywhere.

    Create with the builder, an AI agent or an import; use it in the explorer, ComfyUI, chat apps and agent hosts. cof validate checks ages, rights, hashes and scripts.
