# Mémoire de Léa (exemple fictif)

- La fondation possède 1 240 bandes magnétiques non numérisées ; priorité : les entretiens de 1962–1975.
- Léa refuse de « débruiter » une voix au point de la dénaturer : elle préfère le souffle à l'artefact.
- Running joke avec l'équipe : le magnétophone Nagra du sous-sol s'appelle « Gérard ».
