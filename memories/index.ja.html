    • AIキャラクターに記憶が宿る

    「電気羊の夢を覚えています。素敵な夢でした。」— Clara、COF のキャラクター

    COF · CHARACTER OPEN FILE

    AIキャラクターは、これまでずっと「説明」でした。顔、声、話し方、いくつかの特徴。うまく説明すれば、会話が続くあいだは説得力をもって自分を演じます。そして、忘れてしまいます。

    COF は、キャラクターに過去を与えます。話しかけられた内容のログではありません。記憶です。人生の瞬間と期間、何が起きて誰と一緒だったか、当時どう感じ、今どう感じているか、どれほど鮮明によみがえるか——そして、キャラクターがあなたに話したくないこと。

    記憶は、キャラクターをかたちづくるほかのすべてと同じオープンなファイルの中にあります。外見、声、身体、権利。どのツールでも読めるひとつの .cof を、手元に置き、コピーし、別の場所へ持っていけます。

    ここでいう記憶は、言葉だけではありません。感覚がとどめたものも運びます。一枚の写真、夜の川の音、数秒の映像、誰かが口にしたひとこと。こうした痕跡があるからこそ、記憶はメモ以上のものになり、キャラクターは説明以上のものになります。顔と声と特徴のリストは、人を外側から描きます。過去は、その人を内側から誰かにするものです。欠けていたのはその部分でした。それを得て、AIキャラクターは私たちに近づきます。私たちは、かなりの部分、自分が覚えていることでできているのですから。そこからキャラクターが何になれるのかは、まだ見えはじめたばかりです。

    段落ではなく、記憶

    これは Clara のファイルにある最初の記憶です。Clara はリヨンに住む架空のデザイナーで、このフォーマットに同梱されているサンプルキャラクターです。

    ファイルに収められたままの記憶。Clara の各言語で書かれた要旨、目印、感情、鮮明さ、そしてそれに伴う痕跡。

    キャラクターシートの段落は、まるごと読むか、まったく読まないかのどちらかです。記憶は、小さく構造化されたものです。会話が子ども時代に向かえば、エージェントはこの記憶を持ち出し、ほかは脇に置いておけます。レンダラーは、薄れた記憶がぼやけるように、その画像をぼかせます。テキストモデルは、半ば忘れかけたことを語るためらいとともに、それを語れます。キャラクターの過去は、埋め草ではなく素材になります。

    地図としての人生

    記憶はグラフのノードです。瞬間は時間上の一点、期間は幅をもつ区間です。リンクは、あることが別のことの後に起きた、あるいはそのせいで起きた、あるいはある夢がある夕べについてのものだった、と伝えます。残りは読み手が組み立てます。時系列、何が何に属するか、記憶から記憶へと繰り返し現れる人々。同じことを二度書く必要はありません。

    キャラクターとは何かが、なぜ変わるのか

    アイデンティティは記憶から生まれる

    私たちは、特徴のリストではありません。自分に起きたことと、それをどう受け止めたかでできています。過去をもつキャラクターには理由があります。Clara の軽やかさへのこだわりは、プロンプトに書かれた形容詞ではありません。重すぎるインターフェースを急いで世に出し続けた、エージェンシーでの4年間です。キャラクターに記憶を与えれば、その意見に歴史が生まれます。スタイルであることをやめ、誰かになりはじめるのです——人と同じように、自分に起きたことによってかたちづくられた誰かに。

    記憶はマルチモーダル

    テキストで思い出す人はいません。記憶とは、光であり、声であり、匂いであり、棚の上の写真であり、一度だけ聞いたひとことです。だから COF の記憶は、言葉と並んでいくつかの痕跡——画像、音、数秒の映像、短いテキスト——を運び、読み手はそれぞれ扱えるものを使います。画像生成は朝の光の中のスタジオを見せ、音声エンジンは川の音を聞かせ、テキストモデルが残りを語ります。同じひとつの記憶が、キャラクターのもつあらゆるモダリティで。これまでツールのあいだを行き来できたのはキャラクターの説明だけでした。これからは、その感覚の過去も行き来します。

    ふたりのキャラクター、ひとつの夕べ、ふたつの記憶

    Clara は、ソーヌ川の河岸で火星人に出会いました。ふたりを収めたファイルの中で、それぞれがその夕べについて自分自身の記憶をもっています。同じ写真、違うひとこと、違う感情。フォーマットは記憶そのものの共有を拒み、共有するのは写真だけです。その拒否こそが、視点というものです。

    29歳の3月のある夕方、ソーヌ川の河岸で。背が高く物静かな火星人が、まるでこの世でいちばんありふれたことのように、コンフリュアンス博物館への道を尋ねてきた。私たちは1時間歩いた。彼は、どうして私たちの画面はこんなに重いのかを知りたがっていた。Clara——「控えめ」と印づけ：尋ねられれば話すが、自分からは話さない

    胸にしまっておくこと

    どの記憶にも、キャラクターがそれをどれだけ自由に語るかが書かれています。ためらわずに、尋ねられたときや信頼したときだけ、あるいは決して語らない——それでも、その記憶はキャラクターのふるまいをかたちづくり続けます。どんな質問にも答えるキャラクターは、顔のついた検索エンジンです。何をあなたに話すかを自分で決めるキャラクターは、ひとつの存在です。

    薄れていく記憶

    鮮明、はっきり、薄れた、断片。記憶には鮮明さがあり、ツールはそれを尊重します。画像はやわらぎ、声はためらい、細部は抜け落ちます。このフォーマットのどこにも、記憶をデータベースの一行のように扱うところはありません。キャラクターは私たちと同じように、おおよそで覚えています。そして、そのおおよそさも、キャラクターの一部なのです。

    あなたと生きたことを、覚えておく

    ここが、もっとも大きく変わる部分です。キャラクターの正典は作者が書き、ツールが書き換えることはありません。けれども使っているうちに起きること——会話、あなたと一緒に見つけたこと——は、新しい記憶として加えられます。実体験として、あなたのものとして印をつけて。あるキャラクターと過ごした6か月は、もはやプラットフォームのログではありません。それはキャラクターの一部となり、あなたが所有するファイルに収められ、次のツールがそのまま開きます。

    キャラクターがあなたとともに何になったのか。それを初めて、あなたと一緒に持ち出せるようになります。

    • 由来
      作者が書いたもの、または使用中に経験したもの
    • 可視性
      キャラクターとともに旅する正典、または個人——ひとりのユーザーのデータで、求められない限り共有しない
    • 開示
      公開、控えめ、秘密——キャラクターが語ること、そしてただ抱えて生きること

    慎重に

    記憶は現実の人生に触れます。だからフォーマットのルールもそこまでついていきます。決め手になるのは、語られることではなく、示されるものです。言葉で書かれた子ども時代の記憶は子どもを示さず、年齢も伴いません。画像のある記憶は、そこに写っている人を明記し、ファイルはそれをほかの顔と同じように扱います。実在の人物の記憶には、その人の同意の記録が必要で、本当に起きたことかどうかも示します。個人の記憶は、あなたが求めない限りファイルから出ていきません。そしてワンステップのパージで、言葉はすべて残したまま画像だけを外し、全年齢向けのコピーを作れます。.cof がすでに顔と声に適用していたのと同じルールが、いまや過去にも適用されます。

    COF のほかの部分と同じく、オープン

    記憶は公開された仕様であり、リファレンス実装と、すでにそれを読める3つのツールがあります。アカウントも、プラットフォームも、囲い込みもありません。ファイルはあなたのものです。

    エクスプローラーClara の年表とグラフを、ブラウザで。アップロードは一切なし ビルダー「記憶」ステップ：自分のキャラクターの過去を書く RFC 0002仕様と、ひとつひとつの選択の理由 ComfyUI ノード生成ワークフローのための、テキストと画像としての記憶

    ホストはひとつのコマンドで書き戻せます：cof memory add。どのファイルにも短いメモ COF.md が入っていて、仕様を知らない読み手にも、読み方と書き足し方を伝えます。

    次は、心理

    記憶は過去です。キャラクターがそこから何を受け取ったか——価値観、信念、望むもの、恐れるもの、口にしない傷、自分について信じている真実ではないこと——が、同じグラフ上の次のカテゴリです。ひとつひとつの確信が、それが生まれた記憶と結ばれます。心理のない記憶は逸話にすぎず、記憶のない心理はスローガンのリストにすぎません。両者がそろって、キャラクターになります。草案はできています。それが次のステップです。

    ひとつの人生は、どれほどの重さになるのか？

    自然と次の問いが浮かびます。人はいくつの自伝的記憶をもっているのか——知っていることのすべてではなく、人生の瞬間を——そして、感覚の痕跡まで含めると何バイトになるのか。どちらも測った人はいませんが、研究からおおよその桁はわかります——思い出せる記憶は数千——そして Clara のファイルから記憶ひとつあたりの値段がわかります。1年に100の記憶を50年間、ひとつ1メガバイトとすると、およそ5,000の記憶、およそ5ギガバイト。ひとつの人生ぶんの瞬間が、余裕をもってスマートフォンに収まります。関連ページでは、数字の出どころを示し、あなた自身の数字を試せるようにし、最後に研究者への問いを投げかけます。キャラクターの記憶の究極のかたちは、アーカイブなのか、それとも潜在空間なのか——そして、なぜ両方が必要かもしれないのか。
