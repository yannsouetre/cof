    一个可以阅读、编辑并随身带走的心理——每一条信条都与造就它的记忆相连。

    “简约是一种尊重。”——Clara，一个 COF 角色

    COF · CHARACTER OPEN FILE

    有了记忆，AI 角色便有了过去。它仍然缺少的，是它从这段过去中形成了什么：它看重什么、相信什么、想要什么、害怕什么，它闭口不谈的那道创伤，以及它对自己深信不疑、却并不真实的那些看法。

    COF 1.2 为角色赋予心理。不是提示词里的一串形容词，而是一组信条，每一条都有权重、日期、理由，以及它所源自的记忆。它和其余一切存放在同一个开放文件里：外貌、声音、身体、权利、记忆。一个 .cof，任何工具都能读取，你可以保存、复制，并带到别处。

    是信条，不是形容词

    这是 Clara 心理中的二十三个节点之一。Clara 是一位来自里昂的虚构设计师，也是随格式一同发布的示例角色。

    节点在文件中的原貌：Clara 的每种语言各一句话、一个权重、一个稳定性、一个日期，以及指向其来源的链接。

    提示词里的“有环保意识”是一个形容词；模型得去猜它的含义，以及它何时重要。而这是一条有权重、有日期、有理由的信条。智能体可以在话题转到工作时提起它，其余时候将它搁置；它知道核心价值观不会在一次对话中动摇；当你问为什么时，它给出的答案不是临场编造的。

    心理，如一张地图

    十一种节点——创伤、价值观、信念、欲望、需求、恐惧、立场、喜好、习惯、矛盾、规则——彼此相连，也与记忆相连：因为、关于、支持、冲突。它们还与一生中的人物、地点和物品相连：从祖母那里学来的价值观，与一本笔记本相伴的习惯，深夜拿起的一把吉他。其余的由读者拼合：她对某人怎么看，某个地方对她仍意味着什么，四十五岁时什么发生了改变。

    为什么这改变了角色的本质

    为什么

    一串观点是扁平的。“她讨厌笨重的界面——因为曾在一家代理公司匆忙交付这样的界面整整四年”，这才是一个角色。

    没有心理的记忆只是轶事；没有记忆的心理只是口号。

    两者结合，彼此赋予意义——角色便能解释自己，而不是临场编造一个解释。

    它隐藏什么，又不知道什么

    有些信条会坦然说出，有些只在要紧时才说，有些永远不说。还有一些，角色依之行事却并不自知。Clara 在内心深处相信，如果她慢下来，她就会消失。她永远不会说出口——她并不知道。文件知道，所以智能体可以像好演员那样演绎它：体现在她的所作所为中，而不是她的言语里。

    什么会变，什么不变

    核心价值观坚守不移；脆弱的则可能在一次对话中动摇。信条有开始，有时也有结束：四十五岁时，“如果我慢下来，我就会消失”让位于“慢下来并不是消失”。而角色对某人——对你——的态度，也是一个与其他节点无异的节点，带有可以增长的亲近感，被记录、被标注日期，并且归你带走。如今没有任何平台能导出这些。

    角色深信的谎言

    作者可以将一条信念标记为虚假但仍被持有：角色依它生活，读者却心知肚明。故事正是从这里产生的。

    • 权重
      0 到 100 的强度，以及稳定性：核心、稳定、变动、脆弱
    • 时间
      自何时起，直到何时——心理随角色的年龄而变化
    • 自我
      对他人公开、保留或秘密；对自己自知、半自知或不自知

    审慎为之

    虚构作品需要反派，所以 COF 保持宽容：角色可以持有丑恶的信念。但作者可以将节点标记为不当或危险；会采取行动的智能体——使用工具、处理数据——绝不加载危险节点；文件也会声明其中包含什么。工具可以根据角色设定提议一个心理；未经作者勾选，任何内容都不会进入文件。而角色与某位用户相处中形成的东西会被标记为个人内容，只有在你要求时才会离开文件。

    开放，一如 COF 的其余部分

    心理是一份公开规范，配有参考实现，以及如今就能读取它的工具。无需账号，无需平台，没有锁定：文件属于你。

    浏览器以图谱呈现 Clara 的心理，可用游标穿越她的一生——不上传任何内容 Builder“心理”步骤：为你自己的角色写下内心世界 RFC 0004心理规范，以及每项选择背后的理由——另有 RFC 0005：人物、地点与物品 ComfyUI 节点COF Psyche 节点：以文本形式说明角色是谁，供你的工作流使用

    智能体以文本形式获得它：cof export --format agent 会生成一个 SOUL.md，其中的“她是谁”由节点渲染而成。所有 1.0 和 1.1 文件依然有效。

    文本人设，还是心理？

    如今大多数角色只存在于几段文字中：一张 JSON 卡片、一段系统提示词。这行得通，也不会消失。下面是同一个角色拥有心理之后会发生的变化。

    文本人设
    卡片、系统提示词    		COF 心理
    它是什么几段文字节点：带有强度、日期、理由及记忆链接的信条
    编写几分钟——人人都会更久——工具根据你的文本提议节点，由你勾选；生成器和辅助模式已列入 1.3 路线图
    模型接收到的内容每次都是全文只有预设所含的节点，连同其强度
    时间一张快照：每个年龄都得重写自、直到：同一个角色在 20 岁和 45 岁，心理已有变化
    多种用途——工作、亲密、全年龄每种用途一个副本，彼此渐行渐远从同一套节点中挑选的预设
    为什么隐含的——模型临场发挥一种恐惧指向解释它的那段记忆
    隐私全有或全无秘密、保留、个人：用户经历过的仍归用户所有
    兼容所有应用和所有模型COF 工具；其他工具以文本形式获得（SOUL.md）——卡片和 PNG 导出暂不包含它

    互为补充，而非对手：心理最终也会变成文本——但那是经过挑选、标注日期、附有理由的文本。

    多少条信条，才构成一个人？

    随之而来的是一些自然的问题。一个角色需要多少节点——一个人又需要多少？那些流行的人格画像价值几何：大五人格、迈尔斯-布里格斯类型、九型人格的号码、星座？角色真正的未来，难道不是在模型的权重里，而不是在一个文件里？一个配套页面从 Clara 的一次拒绝出发，连问五次为什么，一直追溯到从二十四岁开始的那四年。随后它给出心理学真正统计过的东西，附上出处，提供一个模拟器来检验你自己的数字，并将保存一个心智的三种方式——描述、图谱、权重——并排比较，说明各自能做什么、不能做什么。
