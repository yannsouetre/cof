    「シンプルさは、敬意のひとつの形です。」— Clara、COF のキャラクター

    COF · CHARACTER OPEN FILE

    記憶を得て、AIキャラクターは過去を持ちました。まだ欠けていたのは、その過去から何を受け取ったかです。何を大切にし、何を信じ、何を望み、何を恐れるのか。口にしない傷。そして、自分について信じている、真実ではないこと。

    COF 1.2 はキャラクターに心理を与えます。プロンプトに並べた形容詞のリストではありません。確信の集まりです。それぞれに重み、日付、理由があり、それが生まれた記憶があります。心理は、外見、声、身体、権利、記憶と同じオープンなファイルの中にあります。どのツールでも読めるひとつの .cof を、手元に置き、コピーし、別の場所へ持っていけます。

    形容詞ではなく、確信

    これは Clara の心理を構成する23のノードのひとつです。Clara はリヨンに住む架空のデザイナーで、このフォーマットに同梱されているサンプルキャラクターです。

    ファイルに収められたままのノード。Clara の各言語で書かれた一文、重み、安定性、日付、そして由来へのリンク。

    プロンプトの「エコ志向」は形容詞です。それが何を意味し、いつ効いてくるのか、モデルは推測するしかありません。こちらは重みと日付と理由を持つ確信です。エージェントは、話題が仕事に向かえばそれを持ち出し、そうでなければ脇に置いておけます。核の価値観は一度の会話では揺らがないことも知っています。そしてなぜと尋ねられれば、その場ででっち上げたのではない答えを返せます。

    地図としての心理

    11種類のノード——傷、価値観、信念、欲求、必要、恐れ、態度、好み、習慣、矛盾、ルール——が互いに、そして記憶と結ばれます。なぜなら、について、支持する、矛盾する。さらに、人生に登場する人、場所、モノとも。祖母から学んだ価値観、一冊のノートとともにある習慣、夜に手に取るギター。残りは読み手が組み立てます。誰かをどう思っているのか、ある場所がいまも何を意味するのか、45歳で何が変わったのか。

    キャラクターとは何かが、なぜ変わるのか

    「なぜ」

    意見のリストは平板です。「重いインターフェースが大嫌い——エージェンシーで4年間、それを急いで世に出し続けたから」。これがキャラクターです。

    心理のない記憶は逸話のままで、記憶のない心理はスローガンのままです。

    両者がそろうと互いに意味を与え合い、キャラクターは説明を即興で作るのではなく、自分自身を説明できるようになります。

    隠しているもの、知らないもの

    ためらわずに語られる確信もあれば、必要なときにしか語られないもの、決して語られないものもあります。そして、キャラクターが知らないまま従っている確信もあります。Clara は心の奥で、立ち止まったら、自分は消えてしまうと信じています。彼女は決してそれを口にしません——自分では知らないのです。ファイルは知っています。だからエージェントは、優れた俳優のようにそれを演じられます。言葉ではなく、ふるまいの中で。

    変わるもの、変わらないもの

    核の価値観は揺らぎません。脆弱な価値観は一度の会話の中でも動くことがあります。確信には始まりがあり、ときには終わりもあります。45歳のとき、「立ち止まったら、私は消える」は「立ち止まることは、消えることではない」に席を譲ります。そして、キャラクターが誰か——あなた——に対してとる態度も、ほかと同じひとつのノードです。育っていくこともある温かさが、記録され、日付を持ち、あなたが持ち帰れるものになります。今日、それを書き出せるプラットフォームはありません。

    キャラクターが信じる嘘

    作者は、ある信念を「誤りだが抱いている」と印をつけられます。キャラクターはそれに従って生き、読み手は本当のことを知っている。物語はそこから生まれます。

    • 重み
      0〜100の強さと、安定性：核、安定、変動、脆弱
    • 時間
      いつからいつまで——心理はキャラクターの年齢とともに動く
    • 自己
      他者に対しては公開・控えめ・秘密、自分自身に対しては自覚・半ば自覚・無自覚

    慎重に

    フィクションには悪役が必要です。だから COF は寛容な立場をとり、キャラクターが醜い信念を抱くことも認めます。ただし、作者はノードに「不適切」または「危険」の印をつけられます。ツールやデータを使って行動するエージェントは、危険なノードを決して読み込みません。そしてファイルは、自分が何を含んでいるかを明示します。ツールはキャラクターシートから心理を提案できますが、作者がチェックを入れない限り、何ひとつファイルには入りません。また、ひとりのユーザーとの間でキャラクターがなったものは「個人的」と印がつけられ、あなたが求めた場合にしかファイルの外へ出ません。

    COF のほかの部分と同じく、オープン

    心理は公開仕様であり、リファレンス実装と、今日すでにそれを読めるツールがあります。アカウントも、プラットフォームも、囲い込みもありません。ファイルはあなたのものです。

    エクスプローラーClara の心理をグラフで。彼女の人生をたどるカーソル付き——何もアップロードされません ビルダー「心理」ステップ：あなた自身のキャラクターの内面を書く RFC 0004心理の仕様と、ひとつひとつの選択の理由——そして人・場所・モノを扱う RFC 0005 ComfyUI ノードCOF Psyche ノード：キャラクターが何者かを、ワークフロー向けのテキストで

    エージェントはテキストとして受け取ります。cof export --format agent は SOUL.md を書き出し、その「Who she is」はノードから生成されます。1.0 と 1.1 のファイルはすべて有効なままです。

    人をつくるのに、確信はいくつ必要か

    当然、疑問が湧いてきます。キャラクターにはいくつのノードが必要なのか——では人間には？ ビッグファイブ、マイヤーズ・ブリッグスのタイプ、エニアグラムの番号、星座といった人気のプロフィールにはどれほどの価値があるのか。そして、キャラクターの本当の未来は、ファイルではなくモデルの重みの中にあるのではないか。姉妹ページでは、Clara のある断りから出発してなぜを5回問い、24歳で始まった4年間にまでたどり着きます。そのうえで、心理学が実際に数えてきたものを出典つきで示し、あなた自身の数字を試せるシミュレーターを用意し、心を保存する3つの方法——記述、グラフ、重み——を並べて、それぞれにできること、できないことを示します。
