    • KI-Figuren haben jetzt ein Innenleben

    Eine Psyche, die Sie lesen, bearbeiten und mitnehmen können — jede Überzeugung an die Erinnerung gebunden, aus der sie entstanden ist.

    „Einfachheit ist eine Form von Respekt.“— Clara, eine COF-Figur

    COF · CHARACTER OPEN FILE

    Mit den Erinnerungen bekam eine KI-Figur eine Vergangenheit. Was ihr noch fehlte, ist das, was sie aus dieser Vergangenheit gemacht hat: was ihr wichtig ist, was sie glaubt, was sie will und fürchtet, die Wunde, über die sie nicht spricht, und die Dinge, die sie über sich selbst glaubt und die nicht stimmen.

    COF 1.2 gibt Figuren eine Psyche. Keine Liste von Adjektiven in einem Prompt — sondern eine Menge von Überzeugungen, jede mit einem Gewicht, einem Datum, einem Grund und der Erinnerung, aus der sie stammt. Sie lebt in derselben offenen Datei wie alles andere: Aussehen, Stimme, Körper, Rechte, Erinnerungen. Eine einzige .cof, lesbar für jedes Werkzeug, die Sie behalten, kopieren und anderswohin mitnehmen können.

    Eine Überzeugung, kein Adjektiv

    Dies ist einer der dreiundzwanzig Knoten von Claras Psyche. Clara ist eine fiktive Designerin aus Lyon, die Beispielfigur, die mit dem Format ausgeliefert wird.

    Der Knoten, wie die Datei ihn speichert: ein Satz in jeder von Claras Sprachen, ein Gewicht, eine Stabilität, ein Datum und Verknüpfungen zu dem, woher er stammt.

    „Umweltbewusst“ in einem Prompt ist ein Adjektiv; das Modell muss raten, was es bedeutet und wann es zählt. Dies hier ist eine Überzeugung mit einem Gewicht, einem Datum und einem Grund. Ein Agent kann sie ansprechen, wenn das Gespräch auf die Arbeit kommt, und sie sonst beiseitelassen; er weiß, dass ein Kernwert sich nicht in einem einzigen Gespräch beugt; und wenn Sie warum fragen, hat er eine Antwort, die nicht aus dem Stegreif erfunden ist.

    Eine Psyche als Landkarte

    Elf Arten von Knoten — Wunde, Wert, Überzeugung, Wunsch, Bedürfnis, Angst, Haltung, Geschmack, Gewohnheit, Widerspruch, Regel — miteinander und mit den Erinnerungen verknüpft: weil, betrifft, stützt, widerspricht. Und mit den Menschen, Orten und Gegenständen eines Lebens: ein Wert, von einer Großmutter gelernt, eine Gewohnheit, die zu einem Notizbuch gehört, eine Gitarre, nachts zur Hand genommen. Den Rest setzen die Lesewerkzeuge zusammen: was sie von jemandem hält, was ein Ort ihr noch bedeutet, was sich mit fünfundvierzig verändert hat.

    Warum das verändert, was eine Figur ist

    Das Warum

    Eine Liste von Meinungen ist flach. „Sie hasst schwerfällige Oberflächen — wegen vier Jahren in einer Agentur, in denen sie sie zu schnell ausgeliefert hat“ ist eine Figur.

    Erinnerungen ohne Psyche bleiben Anekdoten; eine Psyche ohne Erinnerungen bleibt Parole.

    Zusammen gibt jede der anderen ihren Sinn — und eine Figur kann sich erklären, statt eine Erklärung zu improvisieren.

    Was sie verbirgt, und was sie nicht weiß

    Manche Überzeugungen werden frei erzählt, manche nur, wenn es darauf ankommt, manche nie. Und nach manchen handelt die Figur, ohne sie zu kennen. Clara glaubt im Grunde, dass sie verschwindet, wenn sie langsamer wird. Sie würde es nie sagen — sie weiß es nicht. Die Datei weiß es, und so kann ein Agent es spielen, wie eine gute Schauspielerin es täte: in dem, was sie tut, nie in dem, was sie sagt.

    Was sich ändert, und was nicht

    Ein Kernwert hält; ein fragiler kann sich innerhalb eines Gesprächs verschieben. Überzeugungen haben einen Anfang und manchmal ein Ende: Mit fünfundvierzig weicht „wenn ich langsamer werde, verschwinde ich“ dem Satz „langsamer werden heißt nicht verschwinden“. Und wie eine Figur zu jemandem steht — zu Ihnen — ist ein Knoten wie die anderen, mit einer Wärme, die wachsen kann, festgehalten, datiert und Ihr Eigentum zum Mitnehmen. Keine Plattform exportiert das heute.

    Lügen, die die Figur glaubt

    Wer die Figur schreibt, kann eine Überzeugung als falsch, aber geglaubt markieren: Die Figur lebt danach, der Leser weiß es besser. Genau dort entstehen Geschichten.

    • Gewicht
      eine Stärke von 0 bis 100 und eine Stabilität: Kern, gefestigt, im Wandel, fragil
    • Zeit
      seit wann und bis wann — eine Psyche bewegt sich mit dem Alter der Figur
    • Selbst
      offen, zurückhaltend oder geheim gegenüber anderen; bewusst, halb bewusst oder unbewusst sich selbst gegenüber

    Mit Bedacht

    Fiktion braucht Schurken, also bleibt COF großzügig: Eine Figur darf hässliche Überzeugungen haben. Aber ein Knoten kann von seinem Autor als unangemessen oder gefährlich markiert werden; ein Agent, der handelt — mit Werkzeugen, mit Daten —, lädt nie einen gefährlichen Knoten, und die Datei sagt, was sie enthält. Ein Werkzeug kann aus einem Figurenbogen eine Psyche vorschlagen; nichts gelangt in die Datei, ohne dass der Autor es abhakt. Und was eine Figur mit einem Nutzer geworden ist, wird als persönlich markiert und verlässt die Datei nur, wenn Sie es verlangen.

    Offen, wie der Rest von COF

    Die Psyche ist eine öffentliche Spezifikation, mit einer Referenzimplementierung und Werkzeugen, die sie schon heute lesen. Kein Konto, keine Plattform, kein Lock-in: Die Datei gehört Ihnen.

    ExplorerClaras Psyche als Graph, mit einem Regler durch ihr Leben — nichts wird hochgeladen Builderein Psyche-Schritt: Schreiben Sie das Innenleben Ihrer eigenen Figur RFC 0004die Psyche, mit der Begründung jeder Entscheidung — und RFC 0005, Menschen, Orte und Gegenstände ComfyUI-Nodesein COF-Psyche-Node: wer die Figur ist, als Text, für Ihre Workflows

    Agenten bekommen sie als Text: cof export --format agent schreibt eine SOUL.md, deren Abschnitt „Who she is“ aus den Knoten erzeugt wird. Jede Datei der Versionen 1.0 und 1.1 bleibt gültig.

    Eine Text-Persönlichkeit oder eine Psyche?

    Die meisten Figuren leben heute in ein paar Absätzen: eine JSON-Karte, ein System-Prompt. Das funktioniert, und es wird nicht verschwinden. Hier ist, was sich ändert, wenn dieselbe Figur eine Psyche bekommt.

    Wie viele Überzeugungen ergeben einen Menschen?

    Es folgen naheliegende Fragen. Wie viele Knoten braucht eine Figur — und ein Mensch? Was taugen die populären Profile, die Big Five, ein Myers-Briggs-Typ, eine Enneagramm-Zahl, ein Sternzeichen? Und liegt die eigentliche Zukunft einer Figur nicht eher in den Gewichten eines Modells als in einer Datei? Eine Begleitseite geht von einer Absage Claras aus und fragt fünfmal warum, bis hinunter zu den vier Jahren, die mit vierundzwanzig begannen. Dann zeigt sie, was die Psychologie tatsächlich gezählt hat, mit Quellen, einen Simulator, um Ihre eigenen Zahlen zu testen, und die drei Arten, einen Geist festzuhalten, nebeneinander — eine Beschreibung, ein Graph, Gewichte — mit dem, was jede kann und nicht kann.
