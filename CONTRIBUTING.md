# Contribuer

1. Les changements de format passent par une RFC : copiez `rfcs/0000-template.md`, ouvrez une PR.
2. Les vocabulaires (`vocabularies/`) acceptent les PR directes (ajout de descripteurs, traductions, tables de correspondance) — ils sont en CC0, vos contributions aussi.
3. Les exemples de personnages doivent être **100 % fictifs** : aucune personne réelle, aucun personnage sous droits tiers, tags `content` à `none`.
4. Code : Python ≥ 3.11 pour `cli/`, JavaScript sans framework pour `builder/` et `vector/js`. Tests obligatoires pour tout convertisseur.
