# Changelog

## 1.2.1 — 2026-11-08 (platform import, RFC 0006)

**Import a Character.AI export — your characters, and your conversations as their private memories; then take them further than a backup.** Conventions only, no format change: every file written is a valid COF 1.1 / 1.2 file. Character.AI filed for Chapter 11 on 12 October 2026; its users want to keep their characters and their conversations. COF is an independent project, not affiliated with Character.AI (the import page says so in its footer, in six languages).

- **`cof import`** reads, by content: CAI Tools cards (flat PNG, hybrid JSON), Tavern chats and history zips, the legacy `histories` JSON, PersonaText files, SillyTavern chats, Oobabooga chats, and the official Character.AI zip (tolerant reading). The character becomes a COF character (foreign keys to `data.extensions.cai_tools`, `tags.ip.original: false`, conservative rights, `content-unreviewed`, the avatar only with an age or an explicit `--no-avatar`, preset tags for its age and its source). **The conversations of one platform make one period** (« Conversations on Character.AI »), **each conversation a moment `part-of` it** (`lived`, `personal`, `guarded`), titled by the start of the user's first message, with its verbatim transcript in quoted Markdown. Never an invented date (CAI Tools writes the export time: its chats are undated moments, and their period spans 2022 to the export year, both bounds approximate); speakers inferred are said; account files never read; a face under 18 cannot be tagged `sexual` or `nudity`; bounded archives. `--inspect` prints an unknown export's structure with every value redacted. Languages detected (`--lang`, `--card-lang`).
- **Save your Character.AI bots** — a new one-page tool, `import/` (https://yannsouetre.github.io/cof/import/), for the coming weeks: drop your export files at once, check three things (the avatar's age or « without the avatar », your name in the conversations, the content), download your private `.cof` (with your conversations) and a copy without the conversations (for another app). Six languages, offline, nothing sent anywhere; it writes the same memories and transcripts as `cof import`. A file it does not recognise comes with « Report it », a GitHub form that asks for the structure, never the content. Generated from the builder's code (`tools/import-page/gen.py`), so the two never drift.
- **Explorer, Character.AI version** — `viewer/character-ai/`, generated from the explorer (`tools/viewer-cai/gen.py`, rerun after every change to the explorer): a welcome window in six languages, a file opens on its memories graph; the import page links to it.
- **Builder 0.14.1**: « 📥 Import conversations » in the Memories step (a second import of the same platform joins its period), Character.AI cards normalised at the Personality step (their PersonaText conversation offered as a personal memory, never in the card), the build strips a conversation left in an old card; guide and six languages.
- **Explorer 1.2.1**: a long memory text shows folded; an imported conversation shows a one-line summary and its first messages, « + » opens it whole in its own pop-up.
- **RFC 0006** (open for comments until 22 November 2026, as RFC 0004 and 0005); IMPLEMENTING § 7 ter; `cof-author` skill § 3 ter.
- **Bug hunt** (5 agents competing, 56 findings, 39 fixed before release): one content lexicon for the three tools (Unicode word boundaries, NFKC, six languages), a chat at any depth of a card removed, avatars reduced to their image, the official export's flat message list split by chat, swapped speakers turned back, options checked before any write.
- **Site, after the release (8 November evening)** — no change to the format or the tools: share cards (`og:` / `twitter:`) and an illustrated character on the import page; the version DOI; « Example: Wren » in the Character.AI explorer and its welcome window (`viewer/samples/wren-calloway.cof`: a character imported from a made-up Character.AI export, with four looks as presets).
- Tests: cof-cli (the import's own tests, two independent reviews and the bug hunt); builder `cai_import_test.js`, `import_page_test.js` (the page against `cof import`, byte for byte; the Character.AI explorer; an independent review).

## 1.2.0 — 2026-11-08 (RFC 0004 psyche, RFC 0005 people, places, objects)

**Review of 5 November (five competing test agents: safety, explorer, builder, CLI and ComfyUI reader, design — 95 findings, every one re-run by the judge before a fix; report `docs/hunt-1.2.md`)** — tooling only; the rules applied are those of SPEC § 9.4 and RFC 0002 / 0004, read on files rather than ids.
- **Ages and nudity bind to pictures.** `cof validate` keys its image rules on the file's bytes, not on asset ids: the same picture under two ids is one picture (the `mixed-age` fixture had a 14-year-old's face and the intimate placeholder byte for byte); a memory borrowing media (`media_from`) shows them; a picture declared under 18 anywhere, a backstage variant included, is never shown with nudity; a nudity-only use may not reuse an intimate picture; a preset with intimate, nude or sexual content may not reach a minor's picture through an element that carries no age (accessory, node, memory without `age`). `NaN` / `Infinity` are refused (Python's parser took them, and an age `NaN` slipped past every minor rule); a non-finite age is unknown, never adult. In a single-character file, an explicit memory of a real person checks `rights.consent` (scope `intimate` for `explicit: intimate`).
- **A user's data stays home.** `cof export --format agent` no longer copies media a canon memory borrows from a personal one, nor the media of a 1.0 `nudity` memory; `cof extract` drops what inherits a personal node's file, keeps a derived node's words without the personal parent's images, removes a stance's `about` that left with it; SOUL.md (and ComfyUI-COF) never names a personal node a stance is about (« a private matter »); `cof psyche propose` leaves personal memories and nodes out of the bundle (`--keep-personal`); card / PNG export and extract remove a stale `chat_history`; ComfyUI-COF no longer gives personal media through a borrowing memory or an illustrated canon node.
- **Extraction.** `extract --preset` / `--tag` leave behind the media of a real person whose consent record does not travel (it was `--identity` only); `--all-audiences` removes the folder of a removed LoRA or 3D variant (its file stayed). Derived nodes: the « second node with `derives_from` » recipe of RFC 0004 no longer fails on the parent's mirrored strength.
- **Container.** The path grammar uses `\Z` (a name ending in a newline bypassed the executable and pickle checks); symbolic-link entries are refused; a non-byte-exact `mimetype` is warned about; a manifest that is not a JSON object is an error, not a crash. `cof psyche propose` accepts a bare list and prose around the JSON, and refuses (no traceback) a null node or an infinite strength. « Who they are ».
- **Builder.** Four ways to run script from an opened file are closed (kinds, garments, languages and paths are checked at opening; `sel()` escapes values and labels); nothing of the previous file's rights (permissions, consent, proof) survives opening another; a child preset's empty list (« nothing », e.g. the text-only 14-year-old of example 07) is kept instead of inheriting the adult's photos and LoRA; ages in months (memories, nodes, `age_override`) are read as months, and the age `basis` is kept; the checks read the ages of memory media and node images (an adult preset with a memory at 10 and `allowSexualUsage`); the all-audiences build drops 1.0 `nudity` memory media; a built card never keeps a chat; a real person's consent keeps `excluded`, `revocation_uri`, URI proofs and its proof file, and a missing proof is an error of the checks; permission keys without a control (`ageRating`, `minUserAge`, `aiDisclosure`) are kept.
- **Explorer.** Nude images are shown (blurred, click to reveal) only on a preset of a known age of 18 or more — memory media and node images counted — and intimate images never, wherever they are referenced; inflating stops at a ceiling (a 3 MB bomb crashed the tab); a file that cannot be shown leaves the previous one in place; page links accept `http(s)` only.

**Awareness, valence, end of a node (RFC 0004 § 3 nonies, Yann's choices C1–C3, 3 November)** — three optional fields on psyche nodes: `aware` (`yes` default, `partly`, `no`: whether the character knows this about itself — not `disclosure`, what it tells others), `valence` (stance and taste only, −100 … +100: which way it leans; the affinity toward the user is a stance `about: user` with a valence), `until` (a point: when the character let the node go — a node that changes is a second node whose variant `derives_from` the first).
