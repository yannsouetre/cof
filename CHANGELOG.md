### Review of 28 October (autonomous audit by independent agents: cof-cli, builder, explorer, pages, ComfyUI-COF — every finding re-verified before a fix)

- **cof-cli: names and paths read from a manifest never leave the output.** A skill `name` with `..`, an asset `path` outside the folder or a character name shaped like a path could write outside the output of `export --format agent`, `extract`, `merge` and the default output names of `export`; every copy now goes through one guard (`container.safe_rel` / `copy_rel`), a skill name must be a plain folder name, and default output names are slugged. Regression test.
- **cof-cli: archive hardening.** A second entry of the same name is an error (`duplicate entry` — readers disagreed on which one won, and the validator saw the last one); a directory entry (`zip -r`) is skipped instead of crashing `unpack` and `validate`; a structurally unsafe archive (compression bomb, duplicate, bad path) is not opened further; hashes are streamed, so a declared asset is never held whole in memory.
- **cof-cli: `merge` keeps memories whole.** `media` and `files` asset ids are remapped like the other lists (a file with deduplicated media — Clara's manga copies — merged alone gave five dangling `media`); when variant ids collide, the memory nodes' `links`, `where.environment` and `media_from` follow the renames. Temp folders of merged `.cof` inputs are removed. Regression test.
- **cof-cli: `extract --preset` / `--tag` on a cast file** drops the relations to the characters that leave the file and relabels the `who` entries that named them, as `extract --identity` already did (`extract --preset default` on example 11 did not validate). Regression test.
- **cof-cli: `memory add` is atomic on a folder** (a refused add left the node file and the manifest edit behind, and every later add failed on the old error) and refuses `nan`, infinite or absurd ages; `.cof` inputs no longer leave a temp folder per run. A missing file, a non-ZIP input or an unreadable manifest give one `ERROR` line instead of a traceback. Regression test.
- **cof-cli: the validator never raises on a wrongly typed sub-file** (a `where` given as a string, `links: true`, `weights.json` with a string `base_model`, a card whose `data` is a number): the semantic rules read only nodes that pass their schema, and the three remaining unguarded reads are guarded. Found by a type-mutation fuzzer (600 runs per example, 15 crash sites, now 0). Regression test.
