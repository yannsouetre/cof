# COF launch clip (motion graphics)

`index.html` is a 38-second animation driven by a single `render(t)` function: open it in a browser to watch it loop, or render it frame by frame to video (1920×1080, 30 fps) with Playwright and ffmpeg.

Images: Clara Mercier and Martien, fictional COF example characters (AI-generated, from `spec/examples/10` and `04`). Fonts: Bricolage Grotesque and IBM Plex (SIL Open Font License, see `fonts/`).
