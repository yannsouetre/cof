# COF Builder (v0.4)

Une seule page HTML, **sans dépendance ni réseau** : ouvrez `index.html` dans un navigateur récent (Chrome/Edge/Firefox/Safari 2023+) — en local par double-clic, ou hébergée (GitHub Pages, Space Hugging Face statique). Tout reste dans le navigateur ; seule la passerelle de cohérence (optionnelle) envoie des données au point d'API que **vous** configurez.

**Version facile** (bouton en haut à droite) : nom + zone de dépôt, un fichier par média (fiche, image, voix), un preset, âge apparent demandé dès qu'une image est déposée ; tout le reste passe par la version avancée (défaut). Interface en FR/EN/DE/ES/ZH/JA (sélecteur en haut à droite ; aides longues et messages de contrôle encore en français).

Parcours avancé : **1 Identité(s)** (nom, fictif, morphologie ; **pas d'âge** — il est porté par les déclinaisons ; plusieurs identités = casting) **→ 2 Éléments** (7 catégories : 📝 personnalité, 🖼️ apparence, 💾 poids d'identité, 🧊 3D, 👄 voix, 🏃 postures, 🎥 mouvements ; chaque déclinaison déclare son **type** ; personnalité : types *texte structuré* / *texte libre* / *import d'un fichier* (zone glisser-déposer ; la déclinaison prend le type du fichier déposé) (carte PNG/JSON, .md/.txt, image sans fiche → proposée en « Photos en vrac ») ; character sheet à planche unique par défaut (option « plusieurs planches » + avertissement de cohérence) ; glisser-déposer d'images, d'audio (transcription facultative), de modèles 3D, de clips, de vidéos plafonnées à 20 Mo) **→ 3 Presets** (identité + trois états par déclinaison et catégorie — **absent / proposé / par défaut** : par défaut = appliqué, proposé = disponible pour ce preset seulement ; un seul « par défaut » par type sauf cumulables ; **photo principale** = l'allure par défaut ; postures et mouvements en **bibliothèques** — cases multiples, rien d'obligatoire à l'inférence, « par défaut » optionnel ; conflits de régions du corps affichés en direct ; héritage, âge par preset, surcharge de permissions optionnelle) **→ 4 Droits** (permissions VRM-like, consentement avec preuve) **→ 5 Contrôles** (erreurs de structure bloquantes ; cohérence heuristique non bloquante ; passerelle IA OpenAI-compatible ; priorités) **→ 6 Build** (classe de taille, redimensionnement/compression des images, dérivé Canny optionnel, export `.cof`, carte PNG ccv3, SOUL.md/IDENTITY.md, aperçu du manifeste). « Ouvrir un .cof » recharge un fichier v0.5 (un v0.4 est migré à la volée) ; « Exporter un preset » produit un `.cof` allégé ; « Importer et fusionner un .cof » (étape Build) ajoute un preset exporté ou un autre personnage au fichier courant (mêmes nom + surnom ⇒ même identité, sinon nouvelle identité).

Technique : ZIP écrit à la main (`mimetype` stocké en première entrée, `manifest.json` en seconde, binaires stockés, JSON en deflate via `CompressionStream`), SHA-256 via WebCrypto, chunks PNG `chara`/`ccv3` lus et écrits en JS, KPI de complétude calculé avec les mêmes règles que `cof-cli` (vérifié : scores identiques).

Pas encore dans ce v0 (prévu) : découpage automatique des planches, détection des vues et des styles, mesures acoustiques, bonhomme OpenPose, PiDiNet/HED en ONNX, génération des SOUL/IDENTITY par preset autre que le défaut, « enregistrer sous » un preset, fusion de fichiers.
