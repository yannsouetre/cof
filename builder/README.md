# COF Builder (0.13)

A single HTML page, **with no dependencies and no network**: open `index.html` in a recent browser (Chrome/Edge/Firefox/Safari 2023+) — locally by double-clicking, or hosted (GitHub Pages, static Hugging Face Space). Everything stays in the browser; only the (optional) coherence gateway sends data, to the API endpoint that **you** configure.

**Easy mode** (button at top right): name + drop zone, one file per medium (character card, image, voice), one preset, apparent age requested as soon as an image is dropped; everything else goes through advanced mode (the default). In advanced mode, the **📖 Guide** button opens a short guide (also in [docs/builder-guide.md](../docs/builder-guide.md)). A file that holds more than easy mode handles (several characters or presets, several elements of one medium, poses, LoRA…) cannot be switched to easy mode: a window says why. Interface in FR/EN/DE/ES/ZH/JA (selector at top right; a few long check messages and alerts are still French in the other languages).

Advanced flow (7 steps since 0.13): **1 Character(s)** (several characters = a cast: each one owns its elements, presets and rights; a header selector sets the character you work on) (name, fictional, morphology; **no age** — it is carried by the variants; several identities = casting) **→ 2 Elements** (8 categories, plus the memories of step 3: 📝 personality, 🖼️ appearance, identity weights (LoRA), 🧊 3D, 👄 voice, 🏃 postures, 🎥 motion, 📁 files — agent skills, memories, documents; each variant declares its **kind**; personality: kinds *structured text* / *free text* / *file import* (drag-and-drop zone; the variant takes the kind of the dropped file) (PNG/JSON card, .md/.txt, image without card → offered as "Loose photos"); character sheet with a single sheet by default ("several sheets" option + coherence warning); drag-and-drop of images, audio (transcription optional), 3D models, clips, videos capped at 20 MB) **→ 3 Memories** (COF 1.1, RFC 0002: moments and periods, gist per language, when / where / with whom, feelings, clarity, media, typed links, tags; the explicit flags are greyed with a reason until the lived age and every shown person are known adults) **→ 4 Presets** (identity + three states per variant and category — **absent / offered / default**: default = applied, offered = available for that preset only; one default per kind except stackable ones; **primary image** = the default look; guided deletion from *Elements* only (one page per preset where the item is default, optional replacement, summary); postures and motion as **libraries** — multiple slots, nothing required at inference, optional "default"; body-region conflicts shown live; inheritance, per-preset age, optional permissions override) **→ 5 Rights** (VRM-like permissions, consent with proof) **→ 6 Checks** (blocking structural errors; non-blocking heuristic coherence; OpenAI-compatible AI gateway; priorities) **→ 7 Build** (size class, two purges — all audiences, drop personal memories —, image resizing/compression, optional Canny derivative, `.cof` export, ccv3 PNG card, SOUL.md/IDENTITY.md, manifest preview). "Open a .cof" reloads a v0.5 file (a v0.4 file is migrated on the fly); "Export a preset" produces a lightweight `.cof`; "Import and merge a .cof" (Build step) adds an exported preset or another character to the current file (same name + nickname ⇒ same identity, otherwise new identity).

Technical: hand-written ZIP (`mimetype` stored as the first entry, `manifest.json` second, binaries stored, JSON deflated via `CompressionStream`), SHA-256 via WebCrypto, PNG `chara`/`ccv3` chunks read and written in JS, completeness KPI computed with the same rules as `cof-cli` (verified: identical scores).

Not yet (planned): automatic character sheet splitting, view and style detection, acoustic measurements, OpenPose stick figure, PiDiNet/HED in ONNX, SOUL/IDENTITY generation for presets other than the default, "save as" a preset.
