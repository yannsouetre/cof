# COF Builder (0.7)

A single HTML page, **with no dependencies and no network**: open `index.html` in a recent browser (Chrome/Edge/Firefox/Safari 2023+) — locally by double-clicking, or hosted (GitHub Pages, static Hugging Face Space). Everything stays in the browser; only the (optional) coherence gateway sends data, to the API endpoint that **you** configure.

**Easy mode** (button at top right): name + drop zone, one file per medium (character card, image, voice), one preset, apparent age requested as soon as an image is dropped; everything else goes through advanced mode (the default). Interface in FR/EN/DE/ES/ZH/JA (selector at top right; long help texts and check messages still in French).

Advanced flow: **1 Identity(ies)** (name, fictional, morphology; **no age** — it is carried by the variants; several identities = casting) **→ 2 Elements** (8 categories: 📝 personality, 🖼️ appearance, identity weights (LoRA), 🧊 3D, 👄 voice, 🏃 postures, 🎥 motion, 📁 files — agent skills, memories, documents; each variant declares its **kind**; personality: kinds *structured text* / *free text* / *file import* (drag-and-drop zone; the variant takes the kind of the dropped file) (PNG/JSON card, .md/.txt, image without card → offered as "Loose photos"); character sheet with a single sheet by default ("several sheets" option + coherence warning); drag-and-drop of images, audio (transcription optional), 3D models, clips, videos capped at 20 MB) **→ 3 Presets** (identity + three states per variant and category — **absent / offered / default**: default = applied, offered = available for that preset only; one default per kind except stackable ones; **primary image** = the default look; postures and motion as **libraries** — multiple slots, nothing required at inference, optional "default"; body-region conflicts shown live; inheritance, per-preset age, optional permissions override) **→ 4 Rights** (VRM-like permissions, consent with proof) **→ 5 Checks** (blocking structural errors; non-blocking heuristic coherence; OpenAI-compatible AI gateway; priorities) **→ 6 Build** (size class, image resizing/compression, optional Canny derivative, `.cof` export, ccv3 PNG card, SOUL.md/IDENTITY.md, manifest preview). "Open a .cof" reloads a v0.5 file (a v0.4 file is migrated on the fly); "Export a preset" produces a lightweight `.cof`; "Import and merge a .cof" (Build step) adds an exported preset or another character to the current file (same name + nickname ⇒ same identity, otherwise new identity).

Technical: hand-written ZIP (`mimetype` stored as the first entry, `manifest.json` second, binaries stored, JSON deflated via `CompressionStream`), SHA-256 via WebCrypto, PNG `chara`/`ccv3` chunks read and written in JS, completeness KPI computed with the same rules as `cof-cli` (verified: identical scores).

Not yet in this v0 (planned): automatic character sheet splitting, view and style detection, acoustic measurements, OpenPose stick figure, PiDiNet/HED in ONNX, SOUL/IDENTITY generation for presets other than the default, "save as" a preset, file merging.
