Identité

Les seuls champs obligatoires du format, avec les droits. Tout le reste est optionnel.

Personnage

Éléments et déclinaisons

Chaque type d'élément peut avoir plusieurs déclinaisons (visage 1, visage 2…). Rien n'est obligatoire ; les presets les combinent à l'étape suivante.

Presets

Un preset = une combinaison de déclinaisons. Le preset par défaut est chargé à l'ouverture du fichier ; sa vue de visage de face devient la vignette.

Un preset peut hériter d'un autre (extends) et ne surcharger que quelques emplacements.

Droits

Défauts restrictifs (modèle VRM). Le consentement est obligatoire dès qu'une personne réelle est impliquée.

Consentement (personne réelle)
Licence et provenance

Contrôles

Jamais bloquants : le format rend visible, il n'interdit pas. Les erreurs de structure, elles, empêchent le build.

Résultats
  • Aucun contrôle lancé.
Cohérence par IA (optionnel) — passerelle API OpenAI-compatible

Le builder envoie le dossier du preset (textes, vignettes, descripteurs) et attend un JSON {score, issues[]} — contrat dans docs/coherence-api.md. Le score est stocké avec le nom du modèle ; il ne bloque rien.

Priorités (quand plusieurs représentations décrivent la même chose)

Défauts par usage cible (jeu 3D : avatar d'abord ; chat texte : descriptif d'abord) : appliqués automatiquement, modifiables dans le manifeste.

Build

Génère le fichier .cof (ZIP : mimetype en première entrée, manifeste en seconde, binaires stockés sans compression, hashes SHA-256).
