Identité

Les champs marqués * sont obligatoires (nom, fictif ou non, morphologie — l'âge est porté par les déclinaisons) : ce sont, avec les droits, les seules obligations du format. Tout le reste est optionnel. Un fichier peut contenir plusieurs identités (casting) : chaque preset se rattache à l'une d'elles.

Éléments et déclinaisons

Huit catégories par nature de média. Chaque déclinaison déclare son type ; rien n'est obligatoire ; les presets combinent les déclinaisons à l'étape suivante.

Une déclinaison = un ensemble cohérent d'une seule chose (un visage, une coiffure, un vêtement, un lieu…) : plusieurs photos servent uniquement à montrer différents angles. Seule « Photos en vrac » mélange, et c'est assumé.

Presets

Un preset = un personnage + une combinaison de déclinaisons. Une déclinaison par type, sauf les cumulables (vêtements, accessoires, pilosité, particularités, environnements, plusieurs LoRA) — vêtements et accessoires vérifiés par région du corps. Le preset par défaut est chargé à l'ouverture ; sa vue de visage de face devient la vignette.

Un preset peut hériter d'un autre (extends) et ne redéfinir que certaines catégories.

Droits

Défauts restrictifs (modèle VRM). Personne réelle : le consentement est recommandé, et obligatoire pour la nudité ou le contenu intime ; il se rattache à un personnage.

Contrôles

Les avertissements ne bloquent jamais : le format rend visible, il n'interdit pas. Seules les erreurs (structure, règles d'âge et de contenu) empêchent le build.

Résultats
  • Aucun contrôle lancé.
Cohérence par IA (optionnel) — passerelle API OpenAI-compatible

Le builder envoie le dossier du preset (textes, vignettes, descripteurs) et attend un JSON {score, issues[]} — contrat dans docs/coherence-api.md. Le score est stocké avec le nom du modèle ; il ne bloque rien.

Priorités (quand plusieurs représentations décrivent la même chose)

Défauts par usage cible (jeu 3D : avatar d'abord ; chat texte : descriptif d'abord) appliqués automatiquement ; modifiables dans le manifeste.

Build

Génère le fichier .cof (ZIP : mimetype en première entrée, manifeste en seconde, binaires stockés sans compression, hashes SHA-256).

Options
Le ré-encodage vidéo dans le navigateur arrive dans une prochaine version ; pour l'instant les vidéos sont embarquées telles quelles (plafond 20 Mo, désactivable avec alerte).
