    • Was passt in die Datei?

    Ein KI-Charakter reist in vielen Dateien — einer Karte, einer Markdown-Seele, einem Avatar, einem Erinnerungspaket. Eine Tabelle dessen, was jede davon trägt und was unterwegs verloren geht.

    COF · CHARACTER OPEN FILE

    Niemand hat das so gewählt. Rollenspiel-Apps haben sich auf die Charakterkarte geeinigt, Agenten-Frameworks auf Markdown-Dateien, VTuber auf VRM, Erinnerungsprojekte auf eigene Pakete. Jedes Format ist in seiner Schicht gut und blind für die anderen; ein Charakter, der an mehreren Orten lebt, existiert daher als mehrere Dateien, die auseinanderdriften. COF ist der Container, der sie zusammenhält — ein ZIP mit Manifest, offen, mit Regeln zu Alter, Rechten und Einwilligung. Diese Seite vergleicht es Merkmal für Merkmal mit den Formaten, die es aufnimmt, auch dort, wo COF etwas fehlt.

    Sieben Formate, wie veröffentlicht: Character Card V2 (das chara-PNG und sein JSON, der De-facto-Standard von SillyTavern und Verwandten), Character Card V3 / .charx (der Nachfolger von 2024, ein ZIP mit Assets), Agent-Markdown (SOUL.md, IDENTITY.md, AGENTS.md, wie OpenClaw und Hermes sie lesen), Letta Agent File .af (ein serialisierter, zustandsbehafteter Agent), MacPaw Portable Memory .mem (ein Erinnerungspaket im Besitz der Nutzer, 2026) und VRM 1.0 (der humanoide Avatar auf glTF-Basis, mit dem einzigen ausgereiften Berechtigungsblock). Spaltenweise zu lesen: was eine Datei in diesem Format für sich allein über einen Charakter aussagen kann, ohne die Anwendung, die sie erzeugt hat.

    Mit dem Mauszeiger über eine Markierung fahren, um die Anmerkung zu lesen. Eine grüne Markierung bedeutet, dass das Format die Sache definiert; ob eine bestimmte Anwendung sie nutzt, ist eine andere Frage — die meisten Apps lesen nur einen Teil eines Formats, COF eingeschlossen.

    Was COF gar nicht erst versucht

    In ein einziges PNG passen

    Eine Karte ist ein Bild, das man überall posten kann, und sie bleibt ein Bild. Eine .cof ist ein Archiv. Sie exportiert ein ccv3-PNG (und bald eine .charx), aber die Datei selbst braucht ein Tool, das ZIPs öffnet — das kann jedes.

    Den Agenten ausführen

    Lettas .af liefert die Tools, die Tool-Regeln, die Modellkonfiguration und den Nachrichtenverlauf mit. COF liefert den Charakter und deklariert executableContent: none. Was ihn ausführt, ist bewusst Sache des Hosts.

    Ein Rig definieren

    VRM definiert die Knochen und die Gesichtsausdrücke. COF trägt ein VRM oder GLB als Datei, mit ihren Rechten und Texturen, und ergänzt Posen, Clips und Stimme drumherum. Das Rig bleibt Sache von VRM.

    Eine Löschung beweisen

    MacPaws .mem schreibt Tombstones und ein Audit-Log, sodass sich nachweisen lässt, dass eine vergessene Erinnerung überall vergessen wurde. COF bereinigt beim Export (cof extract) und hinterlässt davon keine Spur — noch nicht.

    Was heute nur COF kann

    Presets

    Eine Datei, mehrere einsatzbereite Kombinationen: derselbe Charakter mit 29 und mit 65, für die Arbeit und für alle, auf Französisch und auf Japanisch. Andere Formate brauchen eine Datei pro Version, und die Versionen driften auseinander.

    Eine Vergangenheit und ein Innenleben, mit einem Warum

    Datierte Erinnerungen mit wer, wo, was und wie es sich anfühlte; eine Psyche aus Werten, Überzeugungen, Wünschen und Ängsten, jeweils verknüpft mit der Erinnerung, aus der sie stammen, mit Stärke und Zeitspanne. Agentenformate bewahren Prosa, Erinnerungsformate Ereignisse; keines bewahrt die Verbindung zwischen beiden.

    Regeln, die ein Validator durchsetzt

    Jedes Preset deklariert ein Alter; Nacktheit oder intime Inhalte mit Minderjährigen machen die Datei ungültig, nicht bloß getaggt. Eine reale Person erfordert einen Einwilligungsnachweis. Ausführbares, Pickles und unsichere Pfade werden abgelehnt. Niemand muss auf den guten Glauben des Autors vertrauen.

    Rückschreiben vom Host

    Was der Charakter in OpenClaw, in Hermes oder in einem Chat erlebt hat, kommt als neue, persönliche Erinnerungen in dieselbe Datei zurück (cof memory add) — und geht mit dem Nutzer mit. Ein Charakter, zwei Zuhause, ein Gedächtnis.

    Aufnehmen statt ersetzen

    Es geht in der Tabelle nicht darum, dass COF die meisten Häkchen sammelt, sondern darum, dass COF von niemandem verlangt, etwas aufzugeben: Eine .cof enthält eine gültige Character Card V3, exportiert ein ccv3-PNG, ein Karten-JSON, SOUL.md / IDENTITY.md und einen kompletten Agenten-Workspace und bewahrt ein VRM als einfache Datei. Die Formate in den anderen Spalten sind seine Ein- und Ausgaben. Wo COF kein Gegenstück hat — ein Rig, eine Laufzeit, eine signierte Löschung —, ist es richtig, das andere Format zu tragen, und die Tabelle zeigt das mit →.

    Die grauen Zeilen sind Versprechen mit Datum, keine Funktionen. Sie stammen aus der öffentlichen Roadmap; die RFCs, die das Format ändern, sind vor ihrer Veröffentlichung für Kommentare offen.
